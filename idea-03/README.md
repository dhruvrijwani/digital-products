# Idea 03 · Scroll-Story Sections pack (Aureline)

One long page with six scroll-animated sections, each built as an independent component that could become a Shopify section. The page uses Lenis smooth scrolling and GSAP ScrollTrigger.

Aureline is an invented home-fragrance and skincare brand. Photos come from Pexels (free licence) and were chosen without visible product branding. A shared warm grade makes them read as one shoot.

## What the demo shows

| # | Section | What happens |
| --- | --- | --- |
| 01 | **Hero text-mask reveal** | The headline rises line by line out of overflow masks while the background image scales down from 1.22× on load. On scroll, the image drifts slowly (parallax) and the text lifts away. |
| 02 | **Pinned product story** | The arched image frame stays pinned while four steps scroll past. Each step wipes in its image with a clip-path (direction follows scroll direction) and the progress line fills with scroll. The active step brightens. |
| 03 | **Horizontal collection rail** | Vertical scroll drives a pinned horizontal track of six products. Each card scales down and turns slightly (rotateY + rotate) based on its distance from the viewport centre. "Add to bag" updates the bag count. |
| 04 | **Marquee proof bar** | Two marquees run in opposite directions: invented press names in large italic serif, and review snippets. Scroll velocity speeds them up (capped). Scrolling up reverses both, then they ease back to cruise speed. |
| 05 | **Split-image reveal** | A full-bleed image is cut into two clip-path halves. A seam line draws in, then the halves part like curtains, scrubbed by scroll, revealing the benefit statement and points behind them. |
| 06 | **Sticky stacking cards** | Four ingredient cards are CSS-sticky with stepped offsets. As each new card arrives on top, the ones beneath scale back and darken (scrubbed), and each card's image settles from 1.18× to 1×. |

**Side label**
- A small fixed label at the bottom-left shows the section number and name (for example "02 / 06, Pinned story") and rolls when the section changes.
- A thin bar shows whole-page progress, and the label turns light over dark sections.

**Tweak menu (bottom-right)**
- **Accent colour:** four presets. Changes the `--accent` CSS variable live (progress lines, marquee dots, split seam, CTA).
- **Animation speed:** 0.5× to 2×, through `gsap.globalTimeline.timeScale()`. Affects intros, wipes, marquees and scrub catch-up.
- **Reduced motion:** tears down every ScrollTrigger and Lenis, then rebuilds the page in calm mode. That means no pins or scrubbing, native scroll, a swipeable product row, a static split statement and simple fades. It starts on if the OS asks for reduced motion.

**Accessibility**
- Real heading structure and alt text on content images.
- Marquee text is duplicated in a visually hidden list so screen readers get it once.
- Tweak controls are a labelled radio group, a range input and a switch. Esc closes the panel.

**Responsive**
- Under 900px the story becomes a pinned 56svh image with steps scrolling beneath it.
- Ingredient cards stack image over text, and rail cards are 72vw wide.
- Crossing the 900px breakpoint rebuilds the scroll setup.

## How to run

```bash
npx serve .          # from the repo root
# open http://localhost:3000/idea-03/
```

Opening `index.html` directly works too: it falls back to `data/page.js`, generated by `node tools/sync-data.mjs`. GSAP, ScrollTrigger and Lenis load from a CDN.

## How the code is organised

`app.js` holds a `Sections` registry. Each entry is `{ render(sectionJson), init(element, sectionJson, opts) }`, with a comment block listing the section's **settings** (numbers a merchant could tune) and **content**.

`data/page.json` is an ordered list of section blocks: `type`, `id`, `label`, `settings` and content. It works much like a Shopify JSON template (`templates/page.aureline.json`), so the page can be reordered or reconfigured from data alone.

`styles.css` has one clearly labelled block per section, plus the chrome, Tweak panel and reduced-motion overrides.

## Shopify mapping (later, not implemented)

| Prototype piece | Shopify home |
| --- | --- |
| Each `Sections[type]` | One theme **section** file, e.g. `sections/aureline-hero-mask.liquid`, with markup from `render()` and a small JS custom element from `init()` reading `data-settings` |
| `settings` in each JSON block | Section **schema settings**: `range` for parallax, speed, depth and scale step; `select` for transition type; `checkbox` for pin on mobile; `color` for accent; `image_picker` for images |
| Repeating content (`steps[]`, `products[]`, `cards[]`, `press[]`, `reviews[]`) | Section **blocks** (step, ingredient card, press name, review), so merchants can add, remove and reorder them |
| Collection rail products | A `collection` setting rendering real `product` objects, with "Add to bag" posting to `/cart/add.js` |
| Ingredients | Metaobject `ingredient` (name, origin, body, image), referenced from the section |
| Reviews in the marquee | Reviews app metafields, or a curated metaobject list |
| Tweak panel accent / speed / reduced motion | Theme settings (`settings_schema.json`): a global accent colour and a motion-intensity range. Reduced motion stays automatic through `prefers-reduced-motion`. |
| Lenis + GSAP loading | Loaded once in `layout/theme.liquid`, or through a theme app extension **app embed** if sold as an app |
