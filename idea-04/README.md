# Idea 04 · Creator Video Pipeline (Loop Studio)

One page with three views that tell an end-to-end UGC story. A creator uploads a clip, the merchant approves it and tags products, and the clip lands on a shoppable storefront wall. All three views share one state object saved in `localStorage`. There is no backend.

Loop Studio is an invented home-workout gear brand. Clips are vertical videos from Pexels (free licence). The product "photos" are small rounded line icons drawn in SVG, so no product imagery is borrowed from anyone.

## What the demo shows

**View switcher.** A segmented control with a sliding clip-path pill. The queue tab carries a live pending badge, and arrow keys move between tabs. On mobile it becomes a bottom tab bar.

### 1. Creator upload
- **Drop zone:** animates on drag-over (border, tint, scale, bouncing icon). It accepts a real video file, or you can click "Use a sample" when demoing without one.
- **Fake upload:** a progress ring fills in uneven bursts while a circular preview of the clip plays inside it. The ring turns green when the upload is done.
- **Fields:** name, Instagram handle (validated), product used (dropdown) and a consent checkbox, each with inline errors.
- **Submit:** a success card draws its checkmark and fires a confetti burst. The clip goes to the top of the queue and the queue badge bumps.

### 2. Merchant approval queue
- **Counters:** Pending, Approved and Rejected count up and bounce on every change.
- **Stack mode:** a Tinder-style card stack in which the top card plays its clip. Drag right to approve or left to reject. "Approve" and "Reject" stamps fade in with the drag, and cards fly out with rotation. The ✓/✕ buttons and the ← / → keys do the same.
- **Attach to products:** approving opens this step. Product chips pop in and the creator's product is preselected. "Publish to storefront" makes the clip live. "Back" flies the card back into the stack.
- **List mode:** a compact table of pending clips with Approve/Reject, followed by the history with status pills. Rejected rows collapse out.
- **Seed data:** six pending clips (plus four already approved).

### 3. Storefront shoppable wall
- **Wall:** a masonry grid of approved clips with varied crops. On desktop, clips autoplay on hover or keyboard focus. On touch they play while in view, and off-screen clips pause.
- **New clips:** freshly approved clips enter with a springy pop and a "New" badge, once.
- **Stories viewer:** opens out of the tapped tile. Progress bars run across the top. Tap the right or left side (or use the arrow keys) to move, and press and hold to pause.
- **Product tag card:** slides up from the bottom with the product, its price and "Add to cart" (the cart count persists). Clips with several products have a "1 more in this clip" switch.

**Shared state**
- Reload the page and everything is where you left it.
- Open the page in two tabs (creator in one, merchant in the other) and they stay in sync through the `storage` event.

**Reset demo**
- Clears storage and restores the seed: 6 pending, 4 approved, empty cart.

**Accessibility**
- Real tabs, labelled form controls, live counters, and focus-trapped dialogs that return focus on close.
- Esc closes the dialogs and keyboard alternatives exist for every swipe.
- Reduced motion swaps flights and springs for fades.

## How to run

```bash
npx serve .          # from the repo root
# open http://localhost:3000/idea-04/
```

Opening `index.html` directly also works: it falls back to `data/seed.js`, generated by `node tools/sync-data.mjs`. GSAP loads from a CDN.

**Limitation (mock only)**
- A file you upload yourself plays for the rest of that session through an object URL.
- Browsers can't keep that file in `localStorage`, so after a reload that clip shows a sample video instead.
- A real build would upload to storage (Shopify Files API or S3) and save the URL.

## File map

| File | Role |
| --- | --- |
| `index.html` | App bar, three view panels, attach dialog, stories viewer |
| `styles.css` | Tokens, switcher, upload, queue stack/list, wall, viewer, mobile tab bar |
| `app.js` | State (load/save/reset), view switching, upload flow, swipe queue, wall and viewer |
| `data/seed.json` | Products, sample clips and the 10 seeded creator clips |
| `assets/video/` | 540×960 vertical clips + poster frames |

## Shopify mapping (later, not implemented)

| Prototype piece | Shopify home |
| --- | --- |
| Creator upload form | **App proxy** page (`/apps/loop/submit`) or a theme app extension **app block** on a "Creators" page, posting to the app backend. Files go through the Admin `stagedUploadsCreate` → `fileCreate` flow. |
| Approval queue | **Embedded admin app** page (Polaris + App Bridge). The swipe stack is an optional "fast review" mode next to a standard resource list. |
| Clip records (status, creator, handle) | Metaobject `ugc_clip` (video file reference, creator name, handle, status, consent timestamp) managed by the app |
| Attach to products | Metaobject field `products` (list of product references), plus a reverse product metafield `loop.ugc_clips` so product pages can query their clips |
| Storefront wall | Theme app extension **app block** (`blocks/shoppable-wall.liquid`) rendering approved `ugc_clip` metaobjects, usable on the homepage or a collection |
| Stories viewer + tag card | JS asset of the same app block. "Add to cart" posts to `/cart/add.js` with the tagged product's first available variant. |
| Cart count | Theme cart bubble updated through the Section Rendering API |
| Reset demo | Demo-only, no production equivalent |
